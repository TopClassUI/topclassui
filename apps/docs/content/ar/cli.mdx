## التهيئة مرة واحدة

يتعرّف <span dir="ltr">`init`</span> على إطار العمل ومدير الحزم، وينسخ الشيفرة المشتركة إلى مجلد واحد، ويضيف سطرين إلى ملف CSS.

```text title="الطرفية"
$ npx topclassui init

Detected Next.js 16.4.2, App Router, TypeScript 5.9.3, Tailwind 4.3.3
Detected npm (default)
CSS entry  app/globals.css
Folder     topclassui
svg → topclassui/components/svg/ (button imports it)
button → topclassui/components/button/ (toast imports it)
toast → topclassui/components/toast/ (base imports it)
base → topclassui/
Added to app/globals.css:
  @import "../topclassui/tokens.css";
  @import "../topclassui/styles.css";
Wrote 106 files and topclassui.json
```

ثم يثبّت <span dir="ltr">`@base-ui/react`</span> و<span dir="ltr">`class-variance-authority`</span> و<span dir="ltr">`clsx`</span> و<span dir="ltr">`tailwind-merge`</span> و<span dir="ltr">`zod`</span>، ويطبع أسطر المزوّد التي تضعها في التخطيط؛ ولا يعدّل التخطيط بنفسه أبدًا. وإذا كان التخطيط يركّب المزوّد من الحزمة توقّف <span dir="ltr">`init`</span>، لأن النسخ تقرأ المزوّد المنسوخ؛ والخيار <span dir="ltr">`--force`</span> يمضي على أي حال.

| الموضع | Next.js مع App Router | Vite |
|---|---|---|
| المجلد | <span dir="ltr">`topclassui/`</span>، أو <span dir="ltr">`src/topclassui/`</span> إن كان في المشروع مجلد <span dir="ltr">`src`</span> | <span dir="ltr">`src/topclassui/`</span> |
| ملف CSS | <span dir="ltr">`app/globals.css`</span> | <span dir="ltr">`src/index.css`</span> |
| المزوّد | <span dir="ltr">`app/layout.tsx`</span>، مع <span dir="ltr">`ThemeScript`</span> في الرأس | <span dir="ltr">`src/main.tsx`</span>، حول <span dir="ltr">`<App />`</span> |

## أضف مكوّنًا

ينسخ <span dir="ltr">`add`</span> المكوّن وكل ما يستورده. اذكر مكوّنًا واحدًا أو أكثر، أو مرّر <span dir="ltr">`--all`</span>.

```text title="الطرفية"
$ npx topclassui add select

select → topclassui/components/select/

# الأمر نفسه مع كل مدير حزم
$ pnpm dlx topclassui add select
$ yarn dlx topclassui add select
$ bunx topclassui add select
```

يطبع <span dir="ltr">`list`</span> كل المكوّنات وما يوجد منها في مشروعك؛ و<span dir="ltr">`--json`</span> يطبع القائمة نفسها بصيغة JSON.

## ملف الإعدادات

يكتبه <span dir="ltr">`init`</span> ويقرؤه <span dir="ltr">`add`</span> و<span dir="ltr">`diff`</span>. الحقل <span dir="ltr">`lock`</span> يسجّل كل ملف منسوخ مع إصداره وبصمته، فاتركه للطرفية.

```json title="topclassui.json"
{
  "version": 1,
  "framework": "next-app",
  "css": "app/globals.css",
  "dir": "topclassui",
  "imports": "relative",
  "packageManager": "npm",
  "lock": {
    "registry": "0.1.0-beta.1",
    "files": {
      "components/button/index.tsx": { "from": "button", "version": "0.1.0-beta.1", "sha256": "…" }
    }
  }
}
```

## عندما تعدّل ملفًا منسوخًا

لا يكتب <span dir="ltr">`add`</span> فوق تعديلاتك أبدًا. يعرض <span dir="ltr">`diff`</span> ما تغيّر ويخرج بالرمز 1 إذا وُجد أي اختلاف؛ والخيار <span dir="ltr">`--overwrite`</span> يستبدل الملف ويطبع الفرق أولًا.

```text title="الطرفية"
$ npx topclassui diff select

select: 1 of 20 files differ
  components/select/classes.ts: modified locally

$ npx topclassui add select --overwrite
```

بعد تحديث الحزمة، يكتب <span dir="ltr">`add --update`</span> الإصدار الجديد من كل ملف لم تلمسه.

## التشغيل بلا أسئلة

```bash title="الطرفية"
npx topclassui init --yes                # يقبل كل القيم الافتراضية
npx topclassui add button --yes
npx topclassui add button --dry-run      # يطبع ما سيكتبه ولا يكتب شيئًا
```

كل أمر يقبل أيضًا <span dir="ltr">`--cwd <dir>`</span> لمشروع خارج المجلد الحالي.

| الخيار | ما يفعله |
|---|---|
| <span dir="ltr">`-y`</span>، <span dir="ltr">`--yes`</span> | يقبل كل القيم الافتراضية دون سؤال |
| <span dir="ltr">`--dry-run`</span> | يطبع ما سيكتبه، ولا يكتب ولا يثبّت شيئًا |
| <span dir="ltr">`--no-install`</span> | يطبع أمر التثبيت بدل تشغيله |
| <span dir="ltr">`--css <file>`</span> | مع <span dir="ltr">`init`</span>: ملف CSS الذي يستورد <span dir="ltr">`tailwindcss`</span> |
| <span dir="ltr">`--dir <path>`</span> | مع <span dir="ltr">`init`</span>: مجلد النسخ |
| <span dir="ltr">`--pm <name>`</span> | <span dir="ltr">`npm`</span> أو <span dir="ltr">`pnpm`</span> أو <span dir="ltr">`yarn`</span> أو <span dir="ltr">`bun`</span> |
| <span dir="ltr">`--examples`</span>، <span dir="ltr">`--no-examples`</span> | مع <span dir="ltr">`add`</span>: يضيف ما تحتاج إليه الأمثلة، أو لا ينسخ أي مثال |

<Callout tone="info">رموز الخروج: 0 تمّ، 1 ثمة اختلاف، 2 خطأ في الأمر، 3 فشل التثبيت.</Callout>
