## أين يوضع

في التخطيط الجذري، محيطًا بكل شيء. تأتي <span dir="ltr">`direction`</span> و<span dir="ltr">`locale`</span> من المسار، ولا تُقرأ من DOM أبدًا.

```tsx title="app/[locale]/layout.tsx" check
import { TopClassProvider } from 'topclassui/provider'
import { ThemeScript } from 'topclassui/theme'

export default async function RootLayout({ children, params }: {
  children: React.ReactNode
  params: Promise<{ locale: string }>
}) {
  const { locale } = await params
  const dir = locale === 'ar' ? 'rtl' : 'ltr'
  return (
    <html lang={locale} dir={dir} data-theme="dark" suppressHydrationWarning>
      <head><ThemeScript /></head>
      <body>
        <TopClassProvider direction={dir} locale={locale}>
          {children}
        </TopClassProvider>
      </body>
    </html>
  )
}
```

## لماذا الاتجاه خاصية

قراءة <span dir="ltr">`document.dir`</span> داخل تأثير (effect) تعطي الخادم جوابًا والمتصفح جوابًا آخر لإطار واحد، فيظهر وميض بالاتجاه الخاطئ. أما الخاصية القادمة من التخطيط فلها القيمة نفسها في المكانين. وفي وضع التطوير يظهر تحذير إذا اختلفت الخاصية عن السمة <span dir="ltr">`dir`</span> على العنصر <span dir="ltr">`html`</span>.

<WrongRight>

```tsx
useEffect(() => {
  setDir(document.documentElement.dir)
}, [])
```

```tsx
<html dir={dir}>
  <TopClassProvider direction={dir}>
```

</WrongRight>

## ThemeScript

سكربت صغير مضمّن، يأتي أولًا في <span dir="ltr">`head`</span>، يقرأ التفضيل المحفوظ ويضبط <span dir="ltr">`data-theme`</span> قبل أول رسم. من دونه تُعرض الصفحة بالوضع الافتراضي ثم تتبدّل، فيظهر وميض بالوضع الخاطئ. السكربت نص ثابت، لذلك تستطيع سياسة أمان المحتوى (CSP) الصارمة أن تسمح به عبر البصمة أدناه.

## في تطبيق صفحة واحدة

في تطبيق صفحة واحدة لا يعمل أي شيء يعرضه React قبل أول رسم، لذلك يوضع السكربت نفسه في <span dir="ltr">`index.html`</span> فوق سكربت الوحدة: الصق نص <span dir="ltr">`THEME_SCRIPT`</span> من <span dir="ltr">`topclassui/theme`</span> داخل وسم <span dir="ltr">`script`</span>. وتكون القيم الأولى لـ <span dir="ltr">`lang`</span> و<span dir="ltr">`dir`</span> و<span dir="ltr">`data-theme`</span> سمات ثابتة على عنصر <span dir="ltr">`html`</span>. وعندما يغيّر الزائر اللغة، حدّث سمات <span dir="ltr">`html`</span> وخصائص المزوّد في الوقت نفسه.
