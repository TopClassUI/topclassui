# breadcrumb: Figma frame vs live build

Verdict: **major**. Blockers 0, major 3, minor 2.

| Area | Figma frame | Built | Fix | Severity |
|---|---|---|---|---|
| Home crumb (icon) | Stage draws an outline house icon (muted, ~10x11 px glyph in a 16 px box, same colour as the links, #989898 peak) as the first crumb, before 'Docs', with no text; Try-it exposes it as 'showHome' (on). | No icon slot anywhere: BreadcrumbItem is { href?, label: string } and index.tsx renders only text links, so the root crumb is the word 'Home'. | Add a home crumb: either `showHome` on BreadcrumbProps rendering `<Svg icon={house} />` inside the first link with an sr-only label from `labels.breadcrumb.home`, or `icon?: IconName` on BreadcrumbItem resolved by the server half (R-7-2). Keep the 16 px box, text-muted colour and the 24 px TOUCH_TARGET. | major |
| Collapsed state | 'Every state' draws 'Docs > ··· > Button': the middle of a long trail folds into one ellipsis crumb (three 1-2 px dots, ~8 px wide, muted #656565) sitting between two carets; Try-it has 'maxItems: 4' and a 'collapse' toggle. | Every item always renders (trail.map with no cap); no maxItems or collapse prop exists in types.ts, boundaries.ts or the demo. | Add `maxItems` (default from constants, clamped with clamp() against BREADCRUMB_BOUNDARIES) that keeps the first and last crumbs and replaces the middle with an ellipsis crumb (a button with `labels.breadcrumb.more` sr-only text that expands, or plain '…' text) between two carets; add a 'collapsed' row to dummy/states.tsx. | major |
| Hover state colour | Hovered link 'Docs' lifts from muted (#a1a1a1) to the body colour (#fafafa peak) and gains a 1 px underline; the caret and the other crumb stay muted. | LINK uses HOVER.link = 'hover:underline' only, with text-muted fixed, so a hovered crumb underlines but stays grey. | Add `hover:text-body` to LINK in classes.ts (or extend HOVER.link in shared/classes.ts to 'hover:underline hover:text-body' if Pagination/Table links are meant to match). | major |
| Hover underline offset | Underline is 1 px thick at 3 px below the baseline (text bottom y=768, line at y=771). | LINK sets underline-offset-4 (4 px) with default thickness. | Use underline-offset-[3px] or a `--tc-underline-offset` knob set to 3 px so the line sits where the frame draws it. | minor |
| Separator caret colour | Stage caret peaks at #686868 and the 'current' row caret at #5d5d5d, visibly darker than the link text (#a1a1a1); the idle/hover rows draw it at #7e7e7e. | Caret inherits text-muted from ITEM and peaks at #7d7d7d (5x10 px glyph), matching the strip rows but lighter than the stage sample. | If the stage is the truth, colour the caret with a line role (`text-line-strong`) on the Svg wrapper instead of inheriting text-muted; otherwise leave as is, since the strip rows already match. | minor |

Missing states: collapsed, hover

Notes: Sample content differs and is not counted: the frame reads 'Docs > Components > Button' with a house icon first; the build reads 'Home > Docs > Breadcrumb'. What matches: 14 px regular text (cap ~10-11 px), muted links (#a1a1a1 peak) and a semibold body-colour current crumb (#fafafa), a 5x10 px caret-right separator inheriting the muted colour, ~14 px gap between crumb text and caret on both sides (gap-2 plus the 16 px icon box), a wrapping single-line row, and the 'idle' row (two muted link crumbs) which the build's 'Home > Shop' demo reproduces. 'hover' is listed as missing because the live states demo cannot capture a pointer state; the build does underline on hover but not with the frame's colour lift (row 3). 'collapsed' is not built at all. The build's third demo row (a lone bold 'Home' current page) is an extra state the frame does not draw. The frame's Try-it also lists a 'separator' select and a 'truncate' toggle; no other separator is drawn so none is counted, and truncation exists in the build (labelMaxLength 200 with CONTAIN/LABEL). Stage text may be 15 px (cap 11 px with Inter) against the built 14 px, but with the system-font swap this cannot be separated from rendering, so it is not counted. Figma stage was read at 1x (960 px wide frame); the strip rows are drawn smaller than the stage and were used only for state shape and colour, not size.
