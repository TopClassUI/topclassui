# combobox: Figma frame vs live build

Verdict: **major**. Blockers 0, major 5, minor 4.

| Area | Figma frame | Built | Fix | Severity |
|---|---|---|---|---|
| icons - leading search icon | A ~16px magnifier icon sits at the start of the input in every state (idle, focus-visible, open, loading, empty, disabled), ~14px from the inner edge, text starts ~8px after it. | No leading icon in any capture; the text/placeholder starts at 16px padding directly. | Render a leading search icon slot (Svg import of the search icon) inside the control with the same ps- padding as Input's leading-icon slot, on by default. | major |
| icons - trailing chevron | No trailing icon on the input; the only trailing glyph is the spinner in the loading state. | A ~16px chevron-down trigger sits at the trailing end (~12px from the edge) in every state, so the control reads like a Select. | Drop the chevron from the default combobox (or hide it behind an explicit prop) and keep the trailing slot for the loading spinner only. | major |
| states - open listbox | Popup opens ~6px below the input, same width as the input, raised surface, ~8px radius, 4px inner padding, drop shadow; rows ~33px tall with 12px side padding; the selected row has a primary tint background, primary text and a 16px check icon at the trailing end; other rows are body text. | Not demonstrated: the basic demo is closed and the states demo has no open sample, so popup surface, radius, shadow, row height, selected tint and the check icon cannot be verified. | Add an open sample (defaultOpen with a typed filter) to the states demo and match the popup spec: raised surface, radius knob, 4px padding, shadow token, selected row bg-primary-soft + text-primary + trailing check Svg. | major |
| states - loading | Loading state keeps the typed text in body colour and shows a ~16px spinner at the trailing end inside the control. | Not demonstrated in the states demo. | Add a loading sample; render the shared spinner in the trailing slot when loading, with data-loading on the root. | major |
| states - empty (no matches) | Empty state shows the typed text 'zzz' and a centred ~11px muted 'no matches' line below the control (no popup drawn). | Not demonstrated; the fourth control in the states demo is only a blank value, no helper text. | Add an empty sample; render the labels.noMatches string from shared/labels in the empty-state element in muted small text. | major |
| states - ring geometry | The 2px primary ring sits ~2px outside the control with a dark gap (ring box ~133px wide vs the 128px control; ~5px taller as well). | The 2px ring (red, invalid sample) is drawn flush over the control border: ring box equals the control box (193px wide, 40px tall), no outward offset, no gap. | Use the shared ring class with the ring-offset knob (outline + outline-offset) instead of an inset or 0-offset ring so the ring sits outside the border. | minor |
| borders - resting control | Idle, loading, empty and disabled controls are a raised surface with a barely visible line; only the focused/open control shows a clear 1px line inside the ring. | Every closed control draws a clearly visible 1px lighter border. | Use the decorative --tc-line (not line-strong) for the resting border, or match the frame's subtle edge on the raised surface. | minor |
| type - control text size | Value and placeholder render at ~15-16px (stage 'jor' ~16px, strip ~15px) at size md. | Value and placeholder render at ~14px at the same height (40px). | Check the md text-size knob for the combobox control against Input md; raise to the frame's size if Input also uses the larger step. | minor |
| states - disabled | Disabled dims the whole control: surface, border and search icon fade together with the muted placeholder (~50% opacity look). | Disabled ('Egypt') dims only the text; surface, border and the chevron stay at full strength. | Apply the shared disabled class (opacity or muted tokens) on the root so icon and surface dim with the text. | minor |

Missing states: focus-visible (primary ring), open (listbox popup with selected row and check icon), loading (trailing spinner), empty (no matches helper text)

Notes: Sample content differs and is not counted: the Figma stage is open with 'jor' typed and 'Jordan' / 'Jordan Valley' in the list; the live basic demo is closed, wrapped in a Field with a 'Framework' label (label is Field chrome, not the combobox) and shows the placeholder 'Search frameworks'. The live states demo shows invalid (red ring), disabled, filled ('Saudi Arabia') and blank-value controls; the Figma strip does not draw invalid or filled-closed, and the build does not draw four of the six Figma states, so those are listed as missing rather than compared. Control height matches at ~40px and radius is comparable (~8px); widths are demo-driven (Figma 234/128px vs live 193px) and not counted. Figma's focus-visible sample wraps 'you@mail.com' onto two lines, which is a Figma text-box artifact, not a spec. Font family ignored as instructed.
