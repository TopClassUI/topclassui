**Check.**

**Negative test.** None. No spec or helper proves that `expectRing`, `expectRowRing`, `pressTo` or `tabStops` fail on a violating input (for example an element with `outline: none`, or two tab stops). `test:mutation` does not run Playwright (DECISIONS.md:108), so the specs are measured only by the claim that the toast specs failed before the hook.ts fix. A small `keyboard.self.spec.ts` on a static fixture would close this: one element with no ring, one roving group with two stops, a key that moves nothing.

**Scope.** It is a hand list: 16 specs, one per component, on chosen demos, not a walk over `src/components/*/dummy`. Untested demos with their own keyboard contract:
- dialog: confirm (alertdialog initial focus), trap-focus
- drawer: non-modal, trap-focus
- dropdown: in-dialog (nested Escape), with-links (Enter follows the link)
- tabs: `orientation="vertical"` (Up and Down; it exists per tabs/README.md:63 and has no demo or spec)
- accordion: first-open
- sidebar: groups
- command: groups

The run uses Chromium only (playwright.config.ts:25), so Tab order for links under WebKit's default is unmeasured. There are no test.skip, fixme, only or eslint-disable lines in e2e/keyboard*.ts.

**Directions.** Every spec loops `DIRECTIONS`. The direction-sensitive keys (tabs and rating, via `inlineKeys`) exercise next, previous and the wrap at both ends in ltr and rtl. Shift+Tab is exercised in every spec except dropdown, where APG defines Tab only.

**Misses.**
- Rating: Space on a focused but unchecked star is never reached (keyboard-rating.spec.ts:50-53 presses Space on the star that is already checked).
- Dropdown: Tab's focus target is unasserted (55.5).
- Non-modal dialog: the open state is unasserted (55.3).
- Popover: the Tab-out target is a harness artifact (55.1).
- Drawer: the first Tab at keyboard-drawer.spec.ts:62 is unasserted.

**Component changes.** Only toast (55.12). It is correct in scope and keeps R-5.12-1, R-8.3-4, R-5.12-2 and R-5.12-3 (one-line comment at hook.ts:53, two-line JSDoc). The one small stale-`from` gap is in 55.12. DECISIONS:15 states the Popover contract wrongly (55.1).
